# 🎲 Economic Strategy Board Game

[🇺🇦 Українська версія](./README.md)

> An economic board game focused on strategy, risk, negotiations, and random events.

---

## 📖 About the Project
This is an economic strategy board game where players move around the board, sign contracts, interact with the bank, earn profits, and face financial risks.

The game focuses on:
- 📊 resource management  
- 🤝 negotiations and deals  
- 🎲 random events  
- 🧠 strategic thinking  

---

## 🗺️ Game Board

![Game Board](./assets/materials/field.jpg)

The board features a closed-loop path around the perimeter and a large central area used for events or game information.

### Tile Types
| Type | Description |
|------|-------------|
| 🏁 Start | Game start |
| 📄 Contract | Signing deals |
| 🏦 Bank | Financial operations |
| 💰 Money | Gain or lose funds |
| 👍 / 👎 Reputation | Bonuses and penalties |
| ❓ Random | Random events |
| ✈️ Travel | Travel or skip turn |
| 🌍 Country | International events |
| ⭐ Special | Unique game rules |

---

## 👥 Players
- **2–6 players**
- Each player has a token and starting capital
- All players begin at the start tile

---

## 🔄 Gameplay
1. Roll the dice  
2. Move your token  
3. Resolve the tile action  
4. Pass the turn  

---

## 🏆 Win Conditions
- Accumulate the highest capital  
**or**
- Meet an alternative victory condition defined by the rules
