# 🎲 Економічна стратегічна настільна гра

[🇬🇧 English version](./README.en.md)

> Економічна настільна гра з елементами стратегії, ризику, переговорів і випадкових подій.

---

## 📖 Про проєкт
Це економічно-стратегічна настільна гра, у якій гравці рухаються по ігровому полю, укладають контракти, взаємодіють з банком, отримують прибуток або стикаються з фінансовими ризиками.

Гра орієнтована на:
- 📊 управління ресурсами  
- 🤝 переговори та угоди  
- 🎲 випадкові події  
- 🧠 стратегічне мислення  

---

## 🗺️ Ігрове поле

![Ігрове поле](./assets/materials/field.jpg)
Ігрове поле має замкнений маршрут по периметру та велику центральну зону, яка використовується для подій або ігрової інформації.

### Типи клітинок
| Тип | Опис |
|----|------|
| 🏁 Start | Початок гри |
| 📄 Контракт | Укладання угод |
| 🏦 Банк | Фінансові операції |
| 💰 Гроші | Отримання або втрата коштів |
| 👍 / 👎 Репутація | Бонуси та штрафи |
| ❓ Випадок | Випадкові події |
| ✈️ Подорож | Подорож або пропуск ходу |
| 🌍 Країна | Міжнародні події |
| ⭐ Спец | Унікальні ігрові правила |

---

## 👥 Гравці
- **2–6 гравців**
- Кожен гравець має фішку та стартовий капітал
- Усі гравці починають зі стартової клітинки

---

## 🔄 Хід гри
1. Кинути кубик  
2. Перемістити фішку  
3. Виконати дію клітинки  
4. Передати хід наступному гравцю  

---

## 🏆 Мета гри
- Накопичити найбільший капітал  
**або**
- Виконати альтернативну умову перемоги згідно з правилами
